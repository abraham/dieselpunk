# Asset policy

Dieselpunk UI evokes the look of factory-management interfaces without using anyone else's artwork.

## What the library contains

- **Procedural materials.** Surfaces use CSS gradients, bevels, outlines, and one generated noise texture. The noise is an original SVG `feTurbulence` pattern, rasterized once as a tiled background. It is not derived from any image.
- **No bundled fonts.** The package ships no font files. This workbench loads Chakra Petch and IBM Plex Mono from `@fontsource` (SIL Open Font License) as development dependencies only.
- **No icons.** The package ships no icons. The icons in this workbench (gear, plus, close, info, warning, check) are drawn originally on a 24 by 24 grid for demos and live in `apps/storybook/src/icons`. They are not part of the published package.
- **No item art.** The package ships none. The item art in this workbench (a gear, an iron plate, a circuit, a speed module, and a copper coil) is original and geometric, drawn on a 24 by 24 grid in `currentColor` so it follows the theme, and lives in `apps/storybook/src/icons/items.ts`. It exists only so the examples show something; it is not part of the published package and is not derived from any game's artwork.
- **No sound.**

## What it must never contain

The library contains no assets or code extracted, traced, modified, or derived from Factorio game files, and it does not use the Factorio logo, item art, typeface, sound effects, or proprietary names as branding.

## What consumers provide

Item and recipe imagery comes from the consumer, through slots or URLs. Consumers are responsible for the rights to the images they use.

Source: `specs/product.md` §4, "Original materials".
